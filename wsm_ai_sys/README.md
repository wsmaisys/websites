# WSM AI SYS — Alpine 3D Web & Production AI Engineering

Production web platform for **WSM AI SYS** — boutique AI engineering, bespoke 3D WebGL spatial platforms, and agentic workflows founded and directed by Wasim M Ansari (IIT Madras Data Science alumnus) in Dehradun, Uttarakhand, India.

## Architectural Highlights

- **Complete 3D Mountain Experience (Richard Mattka-Inspired)**: Native WebGL procedural Himalayan terrain with GPU heightmap FBM synthesis, mathematical topographic contour isolines, dynamic alpenglow lighting, and scroll flight physics.
- **Zero External Dependency & Zero CDN**: 100% self-hosted, independent, and resilient against third-party CDN outages or tracker snooping.
- **Deep SEO, AEO & AI Search Optimization**: Rich Schema.org JSON-LD structured data (`Organization`, `ProfessionalService`, `Person`, `FAQPage`, `BreadcrumbList`, `OfferCatalog`), standardized `llms.txt` and `llms-full.txt` discovery manifests for AI crawlers (Perplexity, SearchGPT, Claude, Gemini, Google SGE).
- **Himalayan Mountainous Color Palette**: Deep Himalayan Slate Granite, Alpine Pine, Glacial Torrent Teal, Peak Snow & Mist, and Terracotta Sunset Alpenglow.
- **Hardened Cybersecurity & Safety**: Strict Content Security Policy (CSP), client-side honeypot spam protection (`botcheck`), rate-limiting, and sanitized DOM mutations.

## Repository Structure

- `index.html` — Complete self-contained single-page platform with embedded WebGL 3D engine, alpine styling, AEO FAQ, and hardened basecamp contact form.
- `DESIGN.md` — Complete architectural specifications, color token system, shader pipeline, and UX design decisions.
- `llms.txt` — Standardized AI search and LLM agent discovery manifest.
- `llms-full.txt` — Comprehensive LLM technical documentation and knowledge base.
- `robots.txt` — Crawl directives welcoming leading AI search crawlers (`GPTBot`, `PerplexityBot`, `ClaudeBot`, `Google-Extended`, etc.).
- `sitemap.xml` — Semantic XML sitemap with freshness timestamps and priority metadata.

## Local Preview & Development

Serve the folder locally with any static web server:

```bash
cd wsm_ai_sys
python -m http.server 8000
# Open http://localhost:8000/
```
