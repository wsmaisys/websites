# Gauri's Diet Clinic

Static clinic landing page for Gauri's Diet Clinic (Mumbai). The site showcases services, programs, pricing, testimonials, and a contact/booking modal.

Live demo: https://wsmaisys.github.io/websites/Gauri_Diet_Clinic/

Tech

- Plain HTML, Tailwind CSS via CDN (development). Images are in the project folder.

Local preview

```bash
cd Gauri_Diet_Clinic
python -m http.server 8000
# open http://localhost:8000
```

Notes

- The site currently uses the Tailwind CDN for convenience. For production builds, consider installing Tailwind locally and generating a minimized CSS bundle.
- Update `logo.jpeg` and any image assets in the folder to change visuals.
